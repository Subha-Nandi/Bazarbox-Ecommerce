# Full-Stack E-Commerce Website

A full-stack e-commerce web application built with JavaScript, Node.js, Express.js, and MongoDB, featuring dynamic product management, product search, shopping cart functionality, and order management through a responsive, multi-page interface.

**Live Demo:** https://bazarbox-ecommerce.vercel.app/
**Source Code:** https://github.com/Subha-Nandi/Bazarbox-Ecommerce

## Features

- **Product Management:** Dynamically fetch and display products from the backend.
- **Product Search:** Search for products through the application interface.
- **Shopping Cart:** Add and remove products, update quantities, and manage delivery options.
- **Order Management:** Create orders and view order history.
- **REST API Integration:** Communicate with backend endpoints using the Fetch API.
- **Database Integration:** Manage product, cart, and order data using MongoDB and Mongoose.
- **Responsive Design:** Adapt the interface to different screen sizes using CSS media queries.
- **Loading State Management:** Implement a reusable loading spinner for asynchronous operations.
- **Multi-Page Interface:** Organize the shopping experience across multiple pages.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **API Communication:** Fetch API, REST APIs
- **Version Control:** Git, GitHub

## Technical Highlights

- Structured backend code using routes, controllers, and models.
- Implemented asynchronous client-server communication using the Fetch API.
- Integrated MongoDB with Mongoose for database operations.
- Connected product, cart, and order functionality to backend API endpoints.
- Implemented responsive layouts using CSS media queries.
- Managed loading states during asynchronous data fetching.
